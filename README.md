# Kara's TV Launcher

## [Kara's TV](karas-tv/) — v2.8.1

An ad-free, animated home screen for Google TV / Android TV (built for the onn. Google TV box). Features:

- live MotionEye / CCTV cameras on the home screen, plus floating camera windows over movies
- a full remote-button remapper (single / long / double press)
- Continue watching and upcoming-episode countdowns (Crunchyroll, Netflix, YouTube…)
- weather with animated icons, and a Discover wallpaper of new movies, shows and anime
- 14 themes with animated backgrounds and a gliding hover glow
- backups that survive "Clear storage"
- IPTV: import M3U playlists and browse them in a grid or list TV guide with now/next guide data (new in the upcoming 2.9 release)
- a LAN-only web editor: change buttons, icons, logo and IPTV from a browser at http://<TV-IP>:8080 (new in the upcoming 2.9 release)
